# Contributing

The initial contribution scope is documentation review and repository organization. Open an issue describing the proposed change and its scope before substantial work.

Scientific experiments, algorithm development, and imported research materials require a separate project decision. This repository's creation is not such a decision.

Document sources and distinguish proposals, observations, and supported conclusions. Do not infer a contributor's participation from affiliation with another repository.

Contributions use the license of the affected file: CC-BY-4.0 for prose and specifications, Apache-2.0 for future code. Contributors retain copyright. Attribution should describe actual contributions and respect consent. No contributor or response-time commitment is announced by this document.
