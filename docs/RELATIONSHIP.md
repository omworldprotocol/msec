# Relationship to OM World

Upstream project: https://github.com/omworldprotocol/om-world

MSEC is intended to be a separately maintained research subproject, not a Git branch or replacement of OM World. OM World retains its existing repository, protocol work, history, attribution, and licenses.

Shared organization hosting does not make every OM World contributor a MSEC contributor. No collaboration, endorsement, review commitment, or inherited maintainership is implied.

Any later reuse must record the upstream URL, exact revision, affected files, applicable license, attribution, and modifications. Citation alone does not establish joint authorship.
