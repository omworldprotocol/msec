# Initial scope

This repository begins with project organization and documentation only.

Included: project remit, independent issue tracking, contribution guidance, licensing, and provenance records.

Future proposals should state their research question, prior work, evidence requirements, limitations, and review process before execution is considered. This document does not authorize research execution.

Existing private reports, code, datasets, or experimental outputs are not imported by the initial setup. No historical result is presented as a result produced by this repository.
